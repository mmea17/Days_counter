# عداد الأيام وحاسبة الفروق الزمنية (Days Counter & Date Calculator PWA)

تطبيق ويب تقدمي (PWA) متكامل مصمم بالكامل باللغة العربية وموجه للعمل من اليمين إلى اليسار (RTL) مع دعم كامل للوضع الليلي والنهاري (Dark/Light mode)، مبني على بيئة **Cloudflare** السحابية الحديثة.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

- **واجهة المستخدم والأطر البرمجية (Frontend):**
  - [Astro](https://astro.build/) بوضع العرض من جانب الخادم (SSR) عبر مهايئ `@astrojs/cloudflare`.
  - [Tailwind CSS v4](https://tailwindcss.com/) مع خط **Cairo** المخصص ودعم كامل لاتجاه النص RTL والوضع الداكن والفاتح.
  - أيقونات [Lucide Icons](https://lucide.dev/).
- **الواجهة الخلفية وخدمات API (Backend):**
  - [Hono.js](https://hono.dev/) كإطار عمل خفيف وسريع لمعالجة مسارات الـ API داخل بيئة Cloudflare Workers / Pages.
- **قاعدة البيانات والتخزين (Database & ORM):**
  - [Cloudflare D1](https://developers.cloudflare.com/d1/) (قاعدة بيانات SQLite سحابية موزعة).
  - [Drizzle ORM](https://orm.drizzle.team/) لتعريف النماذج وضمان الأمان النوعي للبيانات (Type-Safe Queries).
- **التطبيق التقدمي والإشعارات (PWA & Web Push):**
  - ملف بيان التطبيق `manifest.webmanifest` متوافق مع معايير PWA وإمكانية التثبيت على الهاتف والحاسوب.
  - مشغل الخدمة `sw.js` لدعم التخزين المؤقت، العمل بدون إنترنت (Offline Mode)، ومعالجة نقرات التنبيهات.
  - مكتبة `web-push` ومفاتيح VAPID لإرسال التنبيهات الفورية المشفرة للمتصفحات.
- **التنبيهات المجدولة (Cloudflare Cron Triggers):**
  - مشغل مهام مجدول (Cron Trigger) لمعالجة التنبيهات المستحقة مسبقاً (قبل يوم، قبل ساعة، أو تنبيهات دورية) وإرسالها للأجهزة النشطة.

## 🌟 المميزات الرئيسية

1. **الصفحة الرئيسية (Landing Page):**
   - واجهة تعريفية تفاعلية تعرض مميزات التطبيق مع عداد حي توضيحي.
   - تبديل سهل وسلس بين الوضعين الليلي والنهاري دون وميض (Zero-flash theme toggle).
   - زر لتثبيت التطبيق مباشرة (Install App).

2. **نظام المستخدمين وإدارة الجلسات (Authentication):**
   - تسجيل حساب جديد وتسجيل الدخول عبر البريد الإلكتروني.
   - تشفير كلمات المرور باستخدام خوارزمية **WebCrypto PBKDF2** مع Salt عشوائي متوافق 100% مع بيئات Edge.
   - إدارة الجلسات عبر ملفات تعريف الارتباط الآمنة (HttpOnly Cookies) المرتبطة بقاعدة بيانات D1.
   - ربط اشتراكات التنبيهات (Web Push) تلقائياً بحساب المستخدم النشط عبر أجهزته المختلفة.

3. **لوحة التحكم: عداد الأيام والمناسبات (Dashboard):**
   - إضافة، وتعديل، وحذف المناسبات بدقة.
   - كشف تلقائي للحدث:
     - حدث قادم: حساب الوقت المتبقي (العد التنازلي).
     - حدث سابق: حساب الوقت المنقضي منذ حدوثه (العد التصاعدي).
   - تبديل نمط عرض المدة الزمنية:
     - إجمالي الأيام (Days)
     - أسابيع وأيام (Weeks & Days)
     - شهور وأيام (Months & Days)
     - سنوات وشهور وأيام (Years, Months & Days)
   - تخصيص قواعد التنبيهات (قبل ساعة، قبل يوم، قبل 3 أيام، قبل أسبوع، أو تنبيه دوري يومي/أسبوعي).
   - إمكانية اختبار الإشعارات الفورية بضغطة زر واحدة.

4. **حاسبة المدة الزمنية بين تاريخين (Duration Calculator):**
   - اختيار أي تاريخين مع إمكانية التبديل بينهما وتعيين اللحظة الحالية.
   - تفصيل دقيق: سنوات، شهور، أسابيع، أيام، ساعات، دقائق.
   - تحويلات إجمالية: إجمالي الأيام، إجمالي الأسابيع، إجمالي الساعات، إجمالي الدقائق، إجمالي الثواني.
   - حساب أيام العمل الفعلية مع استثناء عطلات نهاية الأسبوع (الجمعة والسبت، أو السبت والأحد) مع إمكانية نسخ الملخص للحافظة.

5. **تطبيق الويب التقدمي (PWA):**
   - تثبيت التطبيق كأنه تطبيق أصلي على أجهزة Android و iOS و Windows و macOS.
   - العمل دون اتصال بالإنترنت مع صفحة مخصصة في حال انقطاع الشبكة.

## ☁️ النشر على Cloudflare Pages

1. اربط المستودع في منصة **Cloudflare Pages**.
2. عيّن إعدادات البناء:
   - **Framework preset:** `Astro`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
3. أنشئ قاعدة بيانات D1 واربطها بالاسم `DB`:
   ```bash
   npx wrangler d1 create days_counter_db
   ```
4. نفذ ملف التهجير الأولي:
   ```bash
   npx wrangler d1 execute days_counter_db --file=src/db/migrations/0000_init.sql
   ```
5. اختياري: عيّن متغيرات VAPID للإشعارات في إعدادات البيئة (أو اعتمد المفاتيح الافتراضية المضمنة):
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `VAPID_SUBJECT`
